Text Analyzer Serverless API

A lightweight serverless text analysis engine designed to compute string metrics in real-time. Built as a proof-of-concept for automated Cloud Native microservices and CI/CD automation.

Technologies Used

  • Python 3.12 & FastAPI
  • Mangum (ASGI Adapter)
  • AWS Lambda & API Gateway
  • GitHub Actions (CI/CD)
  • Tailwind CSS

Engineering Challenges

  • CORS Pre-flight handling
  • Cross-compiling C-extensions
  • Payload v2 mapping in Mangum
  • API Key validation logic

Key Takeaways

  • Targeting manylinux2014 wheels
  • Decoupling CI/CD packaging
  • Cold-start optimization
  • CloudWatch log debugging
